شرح دالة ISNUMBER في Excel بالعربي

تفحص هل القيمة رقم فتُرجع TRUE أو FALSE. مفيدة للتحقق من البيانات وللبحث عن نص داخل خلية مع SEARCH.

الصيغة العامة

=ISNUMBER(value)

الوسائط

  • value: القيمة أو مرجع الخلية المراد فحصها لمعرفة هل هي رقم صحيح. (مطلوب)

الوسيط الذي بين قوسين مربعين في الصيغة العامة اختياري، ويمكنك حذفه.

متى نستخدم ISNUMBER؟

تفحص الدالة ISNUMBER قيمة ما وتعيد TRUE إذا كانت رقماً (ويشمل التواريخ والأوقات لأنها أرقام داخلياً)، وتعيد FALSE إذا كانت نصاً أو خلية فارغة أو خطأ. تفيد في التحقق من البيانات قبل الحساب، وفي اكتشاف الأرقام المخزنة كنص، وفي البحث عن كلمة داخل نص عند دمجها مع SEARCH.

الصيغة

=ISNUMBER(value)

مثال على بيانات

A (القيمة)النتيجة
150TRUE
'150 (نص)FALSE
أحمدFALSE
2026/01/05TRUE
(فارغة)FALSE

الصيغة في B2: =ISNUMBER(A2) تعيد TRUE للرقم و FALSE للنص.

الاستخدام مع IF

لإظهار رسالة عند وجود خطأ إدخال: =IF(ISNUMBER(A2),"سليم","أدخل رقماً").

البحث عن كلمة داخل نص

الدالة SEARCH تعيد رقم الموضع إذا وجدت الكلمة وخطأ إذا لم تجدها، لذلك: =ISNUMBER(SEARCH("عقد",A2)) تعيد TRUE إذا احتوت الخلية على كلمة عقد. يمكن استعمالها داخل COUNTIF أو SUMPRODUCT لعد الخلايا المحتوية على كلمة: =SUMPRODUCT(--ISNUMBER(SEARCH("عقد",A2:A100))).

أخطاء شائعة

  • الأرقام المستوردة من أنظمة أخرى تكون غالباً نصاً، فتعيد الدالة FALSE رغم أنها تبدو أرقاماً؛ حوّلها بـ VALUE أو اضرب في 1.
  • الخلية الفارغة ليست رقماً، فتعيد FALSE.
  • الدالة لا تعالج الخطأ؛ إن كانت القيمة خطأ تعيد FALSE ولا تظهر رسالة الخطأ.
  • نسيان علامات التنصيص حول النص في SEARCH يسبب خطأ في الصيغة.

مثال سريع

=ISNUMBER(SEARCH("أحمد",A2))

النتيجة: تُرجع TRUE إذا كانت الخلية A2 تحتوي على كلمة أحمد

إذا رفض Excel الصيغة

في كثير من إعدادات Windows العربية تُفصل وسائط الدالة بفاصلة منقوطة (;) بدل الفاصلة (,). إذا ظهرت رسالة خطأ عند كتابة الصيغة فجرّبها هكذا:

=ISNUMBER(SEARCH("أحمد";A2))
